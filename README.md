## 🎯 О проекте

Устали часами держать ЛКМ, возводя бесконечные стены, бункеры и укрепления с помощью **Construction Vehicle (CV)** в Foxhole? Ваши пальцы заслуживают отдыха!

**Foxhole AutoClicker** — это простой и эффективный автокликер, созданный специально для зажатия левой кнопки мыши. Просто включите его — и стройте, не напрягаясь.

> ⚠️ **Дисклеймер**: Этот инструмент создан для удобства игроков и не дает нечестных преимуществ. Используйте на свой страх и риск.

---

## ✨ Возможности

- 🖱️ **Удержание ЛКМ** — просто зажимает кнопку, не спамит кликами
- 🎮 **Идеально для CV** — стройте здания без необходимости держать кнопку
- ⌨️ **Управление с клавиатуры**:
  - `F6` — включить/выключить удержание
  - `ESC` — аварийный выход (всегда отпустит кнопку)
- 💻 **Работает в фоне** — можно переключаться на другие окна
- 🔌 **Не требует установки Python** — доступен готовый `.exe` файл

## 🚀 Быстрый старт

### Вариант 1: Скачать готовый `.exe` (для обычных пользователей)

1. Перейдите в раздел **[Releases](https://github.com/matb22/clicker_for_foxhole/releases)**
2. Скачайте `Clicker.exe`
3. Запустите файл **от имени администратора** (важно для перехвата клавиш)
4. Наслаждайтесь строительством!

### Вариант 2: Запуск из исходного кода (для разработчиков)

```bash
# Клонируйте репозиторий
git clone https://github.com/matb22/clicker_for_foxhole.git
cd clicker_for_foxhole

# Установите зависимости
pip install -r requirements.txt

# Запустите скрипт
python source.py
